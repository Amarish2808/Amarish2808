# 🛠️ Cybersecurity Toolkit

Welcome to my personal Cybersecurity Toolkit. This directory serves as a centralized vault for my custom configurations, tool-specific cheat sheets, command references, and automation scripts. 

It is organized by tool category and aligns with the core utilities I use for both offensive (Red Team) and defensive (Blue Team) operations.

---

## 🗂️ Directory Structure

### 🔍 Reconnaissance & Enumeration
* **[Nmap](./nmap/)**: Custom Nmap scripts (NSE), optimized scanning flags for fast/stealth scans, and output parsing scripts.
* **[Gobuster](./enumeration/)**: Wordlist recommendations, directory brute-forcing syntax, and vhost enumeration commands.

### 🕸️ Web Application Security
* **[Burp Suite](./web-security/)**: Notes on Burp extensions, custom Intruder payloads, and match/replace rules for bypassing filters.

### 🔑 Password Cracking & Security
* **[Hashcat](./password-security/)**: Optimized hashcat rules, mask attacks, and references for identifying hash types.

### ⚔️ Exploitation Frameworks
* **[Metasploit](./exploitation/)**: Custom resource scripts (`.rc`) for automating listener setups and frequent module commands.

### 🛡️ Defensive, SIEM & Network Analysis
* **[Wireshark](./defensive/)**: Useful display filters, capture filters, and pcap analysis cheat sheets.

---

## 💡 How I Use This Toolkit
I actively maintain this repository as I encounter new scenarios in my **Red Team Hacker Academy** labs, CTF challenges, and personal research. If a command takes me more than 5 minutes to remember or construct, it gets documented here.
